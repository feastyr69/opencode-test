# 🕹️ opengame - Retro Arcade Portal

A lightweight, pure-web retro arcade portal created as part of a demonstration and test suite for **[OpenCode](https://opencode.ai)**.

---

## 🎯 Purpose

This repository serves as a **testing ground for OpenCode's capabilities**, including:
* Interactive multi-file workspace generation.
* Complex HTML5 Canvas physics engines and game loops.
* Procedural Web Audio API sound synthesis.
* Project refactoring, directory restructures, and git workflows.

---

## 🎮 Included Games

1. **Flappy Bird Arcade (`/games/flappy-bird`)**
   * Smooth gravity physics and floaty controls.
   * Procedural 8-bit audio synth effects (jump swoop, score coin chime, crash explosion).
   * High score persistence via `localStorage`.

2. **Neon Commander (`/games/space-shooter`)**
   * Responsive mouse-driven space ship movement with lerp interpolation.
   * Canvas glowing neon visual effects and parallax space nebula starfields.
   * Enemy waves (Scouts, Fighters, Bosses) and power-up weapon upgrades (`Double Cannons`, `Triple Spread`, `Energy Shield`).

---

## 🚀 How to Run Locally

Simply clone the repository and open `index.html` in any web browser:

```bash
git clone https://github.com/feastyr69/opencode-test.git
cd opencode-test
```

* **Linux:** `xdg-open index.html`
* **Mac:** `open index.html`
* **Windows:** `start index.html`
